ไม่มีการอัปโหลดสคริปต์ขึ้นเซิร์ฟเวอร์ การถอดและเข้ารหัสเกิดขึ้นในแท็บเบราว์เซอร์ของคุณเท่านั้น

    

    

      
เฟสที่ 1: string เท่านั้น

      
เปลี่ยน string literal ทุกตัวให้เป็นอาร์เรย์ byte ที่เข้ารหัส XOR แล้วถอดกลับด้วย bit32.bxor ตอนรันจริง — ตัวแปร ฟังก์ชัน และโครงสร้างโค้ดเดิมยังทำงานเหมือนเดิม

    

    

      
ใช้งานได้บน Roblox / Luau

      
โค้ดที่ได้ใช้ฟังก์ชันมาตรฐานของ Luau (string.char, table.concat, bit32.bxor) จึงรันได้ตรงบน Roblox โดยไม่ต้องพึ่งไลบรารีเสริม
