สเตจ 1 — string → ตัวเลข

แปลงทุก string ในสคริปต์
ให้เป็นแถวตัวเลขก่อนใครจะอ่านมันออก

อัปโหลดไฟล์ .lua หรือ .luau — RoLock จะหา string literal ทุกตัวแล้วแทนที่ด้วยอาร์เรย์รหัสตัวอักษร ที่ประกอบกลับเป็นข้อความจริงตอนสคริปต์รัน ไม่มีการเข้ารหัสซับซ้อน แค่เปลี่ยนตัวหนังสือให้เป็นตัวเลขล้วน ๆ

      02
      
สเตจ 1: string → ตัวเลขล้วน ๆ

      
เปลี่ยน string literal ทุกตัวให้เป็นอาร์เรย์รหัสตัวอักษร แล้วประกอบกลับด้วย string.char ตอนรันจริง ไม่มีการเข้ารหัสเพิ่ม — เก็บไว้เป็นสเตจถัดไป

    

    

      03
      
ใช้งานได้บน Roblox / Luau

      
โค้ดที่ได้ใช้ฟังก์ชันมาตรฐานของ Luau (string.char, table.concat) ล้วน ๆ จึงรันได้ตรงบน Roblox โดยไม่ต้องพึ่งไลบรารีเสริม
